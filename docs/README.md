# Dokumentasi SapiKenal

Dokumentasi proyek dikelompokkan berdasarkan area berikut:

- [`architecture/`](architecture/) — arsitektur dan keputusan teknis sistem
- [`dataset/`](dataset/) — struktur, sumber, lisensi, dan pengolahan dataset
- [`model/`](model/) — pelatihan, evaluasi, dan versi model identifikasi jenis sapi
- [`api/`](api/) — kontrak dan panduan backend API
- [`mobile/`](mobile/) — arsitektur dan panduan aplikasi Android

Tambahkan dokumentasi ketika implementasi terkait mulai dikerjakan. Dataset mentah dan artefak model berukuran besar tidak disimpan di Git.
